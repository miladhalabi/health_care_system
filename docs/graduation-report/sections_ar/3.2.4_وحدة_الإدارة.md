# 3.2.4 وحدة الإدارة (Administration Module)

تعتبر لوحة التحكم الإدارية مركز القيادة والسيطرة للمنصة، حيث تضمن استقرار النظام وتنظيم الأدوار والصلاحيات.

### المتطلبات الوظيفية الرئيسية:

#### 1. إدارة المستخدمين (User Management)
*   يجب أن يتمكن مديرو النظام من تفعيل أو إيقاف حسابات المستخدمين (مرضى، أطباء، صيادلة).
*   يجب توفير أدوات لإعادة تعيين كلمات المرور والتحقق من الهويات.

#### 2. إدارة العيادات والمرافق (Clinic & Facility Management)
*   يجب توفير واجهة لإضافة عيادات جديدة إلى المنظومة الوطنية وتوثيق تراخيصها ومواقعها.
*   يجب ربط الأطباء بالعيادات التي يعملون بها.

#### 3. إدارة صلاحيات الوصول (Access Control Management)
*   يجب تطبيق نظام صارم للصلاحيات القائمة على الأدوار (RBAC)، يضمن أن كل مستخدم لا يرى إلا البيانات الضرورية لعمله.

#### 4. مراقبة النظام والتقارير (System Monitoring & Reporting)
*   يجب توفير لوحات معلومات (Dashboards) تعرض إحصائيات حول عدد الزيارات، الوصفات المصروفة، وأداء النظام بشكل عام.
*   يجب تسجيل سجلات الأحداث (Logs) لمراجعة العمليات الحساسة وضمان المساءلة.
