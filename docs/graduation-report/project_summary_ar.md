# الملخص التنفيذي لمشروع NHR Syria

## نظرة عامة
مشروع **NHR Syria** (National Health Record) هو منصة وطنية رقمية مبتكرة تهدف إلى تطوير منظومة الرعاية الصحية في سوريا. يجمع النظام بين قوة السجلات الصحية الإلكترونية المركزية وإدارة الطوابير الذكية في الوقت الفعلي، مما يوفر تجربة سلسة للمواطنين والكوادر الطبية على حد سواء.

## الأهداف الرئيسية
*   **توحيد السجلات الطبية:** إنشاء ملف صحي رقمي واحد لكل مواطن يرافقه مدى الحياة ويمكن الوصول إليه من أي مركز صحي.
*   **إدارة الانتظار الذكية:** تقليل الازدحام في العيادات عبر نظام مزامنة فورية يتيح للمريض تتبع دوره عن بُعد.
*   **أتمتة الوصفات الطبية:** ضمان دقة صرف الأدوية ومنع التلاعب عبر الربط المباشر بين الطبيب والصيدلاني.
*   **التحول الرقمي الوطني:** المساهمة في بناء بنية تحتية رقمية صحية تخدم صناع القرار ببيانات دقيقة ولحظية.

## النظام البيئي للمنصة
يتكون المشروع من أربع بوابات متكاملة:
1.  **بوابة المواطن:** لإدارة الملف الشخصي، حجز المواعيد، وتتبع الدور.
2.  **بوابة العيادة:** تمكن الأطباء من التشخيص، إدارة الطوابير، وإصدار الوصفات.
3.  **بوابة الصيدلية:** للبحث عن الوصفات الرقمية وتوثيق صرفها بدقة.
4.  **لوحة التحكم الإدارية:** لإدارة المستخدمين، الصلاحيات، ومراقبة أداء النظام وطنياً.

## الحزمة التقنية (Tech Stack)
*   **Backend:** Node.js & Express مع Prisma ORM.
*   **Frontend:** React & Tailwind CSS v4 (تطبيق ويب تقدمي PWA).
*   **Database:** PostgreSQL (قاعدة بيانات موحدة).
*   **Real-Time:** WebSockets عبر Socket.io للمزامنة اللحظية.

## القيمة المضافة
يقدم NHR Syria حلاً جذرياً لمشاكل ضياع السجلات الورقية، وازدحام العيادات، وعدم وضوح الوصفات الطبية. من خلال استخدام تقنيات الـ WebSockets والمعمارية الطبقية، يضمن النظام سرعة فائقة في الأداء وأعلى مستويات الأمان والخصوصية للبيانات الصحية الحساسة.
